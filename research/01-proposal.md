# MFC 离散数学学习网站预研方案

本方案服务于一个有限目标：让大一新生能读懂数学定义、写出基础证明，并理解映射和等价类，为后续 MFC 学习降低起步障碍。目标已确认为斯图加特大学信息安全研究所 Küsters 团队的硕士课程 *Mathematical Foundations of (Post-Quantum) Cryptography*。

**建议保留 18 节离散数学核心，以证明贯穿全程；最多另设两张可选衔接卡。** 每节从一个问题出发，依次给出直觉、精确定义、带理由的例题、少量练习和稍后的新题复验。本网站是第一阶段准备，不替代完整离散数学课，也不覆盖 MFC 的全部背景基础。

## MFC 课程范围与先修核查

研究所[官方课程页](https://www.sec.uni-stuttgart.de/teaching/mathematical-foundations-of-post-quantum-cryptography/)明确将 MFC 标为硕士课程。它说明相关数学理论会自足讲授，但以计算机或数学本科前四学期所教内容为基础。这里的“自足”不能解读为只需高中代数即可学习全课。MIT 的 *Mathematics for Computer Science* 仍仅是教材资源。

| 核查层次 | 结论与证据强度 | 对方案的影响 |
| --- | --- | --- |
| 课程身份与当前开课 | 官方课程页及[教学目录](https://www.sec.uni-stuttgart.de/teaching/)相互印证；目录列有 2026/27 冬季入口 | 不再把课程身份列为待澄清事项 |
| 官方背景要求 | 明确到本科前四学期的概括，未列具体能力或模块 | 本站不能宣称补齐所有必要先修 |
| 正式入课先修 | 未取得模块条目中的正式先修字段 | 不把“未查到”写成“没有正式先修” |
| 考试准入 | 官网要求作业累计至少 50% 分数才可参加期末考试 | 这是课内考核条件，不是入课先修 |
| 当前学期的实际章节与题单 | [ILIAS 2026/27](https://ilias3.uni-stuttgart.de/ilias.php?baseClass=ilrepositorygui&cmdClass=ilobjcoursegui&cmdNode=xi%3Amd&item_ref_id=0&ref_id=4553285)公开信息页可读；讲义与题单未取得 | 不把通用介绍写成逐周大纲，也不虚构 MFC 真题 |

官网介绍涉及代数、代数数论、代数几何、概率以及调和分析。它没有逐周安排或课时分配，因此不能据此断言每学期逐项讲授全部所列专题。下面的能力对应关系是本项目的教学推断，不是官方公布的逐项先修。

| 课程介绍中的方向 | 本站能提供的准备 | 需要保留的边界 |
| --- | --- | --- |
| 群、环、域等代数结构 | 定义阅读、量词、四类证明、映射、等价类与代表元 | 不提前讲完整抽象代数；认识等价类不等于学会商结构 |
| 数论及模运算相关对象 | 整除、同余、模整数；可选的 gcd 与模逆入口 | 不要求先掌握费马定理、二次剩余、数域与格理论 |
| 概率相关内容 | 基础计数；可选的有限等可能模型、补事件与独立条件 | 计数和碰撞例子不能替代完整概率基础 |
| 几何及分析相关内容 | 通用证明语言、集合与映射 | 本站没有补齐线性代数或分析；不提前加入椭圆曲线、测度论或傅里叶分析 |

因此，原定证明、集合、映射和等价类仍是核心。基础计数保留小规模练习，作为有限概率的入口，不提升为整站主线。图论、布尔代数、有限自动机和递推关系求解不进入本次准备站；依据是当前准备目标与公开范围，而不是“官网没写就证明完全无用”。

## 学习起点与强度

进入本站的起点暂定为：会整数与分数运算、代数展开和简单方程，但未系统学过证明。学习本站的 18 节核心不要求微积分、线性代数或编程。这只是本站起点，不是 MFC 的完整背景要求。中文讲解保留常用英文术语。这些是设计假设，不是学生能力结论。

候选规模为 **18 节，每节 35–45 分钟**，每周 3 节，另留 20 分钟回顾。6 周合计约 **12.5–15.5 小时**。这是内容预算，尚未经过新生试学。时间不足时延长周数，不压缩证明练习。已会的内容可通过短诊断跳读。

每节默认只安排 2–3 道即时短练。复杂证明允许拆成两次。每周回顾留一道未见过、未标注方法的新题。无需连续打卡或为完成题量而追加题目。

两张可选衔接卡各预算 20–30 分钟。只有学生已掌握核心、希望提前接触课程对象时才选择，总计另加 40–60 分钟。不把高阶理论提前学完作为完成本站的条件。

## 候选知识结构

表中先修是本方案内的学习依赖，不是 MFC 官方先修。课程身份确认后，核心仍维持 18 节，避免把硕士课内容倒灌到新生准备中。教材简称与链接见[来源说明](03-evidence.md)。

| 节次 | 核心概念与理论 | 先修 | 例题或检验任务 | 停止深度与教材定位 |
| --- | --- | --- | --- | --- |
| L01 集合与对象 | 元素、子集、空集、并交差；整数等常用数集；笛卡尔积 | 基础代数 | 区分 `2∈{1,2}` 与 `{2}⊆{1,2}`；列小集合的有序对 | 不讲公理集合论、悖论与无限基数；Hammack 第 1 章选节 |
| L02 条件命题 | 命题、且或非、蕴含、充要条件、逆否命题 | L01 | “4 的倍数一定是偶数”的逆命题为何不成立 | 只学证明需要的逻辑，不扩展布尔代数；Hammack §§2.1–2.4、2.8 |
| L03 量词与反例 | 任意、存在、量词次序、否定；反例如何推翻全称命题 | L02 | 否定“对每个整数都存在一个更大的整数” | 能用自然语言解释符号；不做形式逻辑演算；Hammack §§2.7、2.9–2.10、9.1 |
| L04 直接证明 | 假设、定义、推导、结论；奇偶与整除定义 | L02–L03 | 写出两个奇数之和为偶数的证明 | 使用定义完成 4–6 行论证；Hammack 第 4 章、Levin §1.4 |
| L05 逆否证明 | 证明 `¬Q⇒¬P`；与逆命题区分 | L04 | 若整数平方为偶数，则该整数为偶数 | 能说清假设和目标；不靠枚举代替证明；Levin §1.4 |
| L06 反证法 | 假设原结论的否定，导出矛盾 | L03–L05 | 假设存在最大整数，再构造更大的整数 | 不加入实分析式存在性证明；Hammack 第 6 章 |
| L07 归纳法骨架 | 命题 P(n)、起始下标、基例、归纳假设、归纳步 | L04 | 前 n 个正整数求和公式 | 只要求普通归纳；Levin §4.5、Hammack §10.1 |
| L08 归纳迁移与选法 | 归纳中的“任意 k”；求和与整除；选择证明方法 | L05–L07 | 证明前 n 个奇数之和为 n²；指出只验若干项的漏洞 | 不解递推关系，不讲强归纳与结构归纳；Levin §4.5 选例 |
| L09 集合证明 | 元素法、子集证明、相等需双向包含 | L01、L04 | 证明 `A∩B⊆A`；为错误集合恒等式找反例 | 只做一至两层集合运算；Hammack §§8.1–8.3 |
| L10 映射的对象 | 定义域、陪域、像；每个输入恰有一个输出 | L01 | 同一规则换陪域后，满射判断是否变化 | 先小集合箭头图，再符号；Levin §5.2 |
| L11 单射与满射 | 同像推出同输入；每个目标元素有原像 | L04、L10 | `f(n)=2n` 从 Z 到 Z 为单射但非满射；到偶整数集则满射 | 使用任意元素说明，避免只验几项；Levin §5.2 |
| L12 双射与逆映射 | 单射且满射；逆函数的定义条件；简单复合 | L11 | 给两个三元素集合建立双射，解释逆映射为何存在 | 不讲无限集合等势；Levin §5.2 |
| L13 关系与性质 | 关系是有序对集合；自反、对称、传递 | L01、L03 | “相差的绝对值不超过 1”不传递：0、1、2 | 不引入偏序、格与图算法；Hammack §§11.1–11.2 |
| L14 等价关系与等价类 | 三性质同时成立；类、代表元、分划 | L04、L13 | 将整数按模 4 分类，解释 `[1]=[5]` | 先做具体分类，再正式定义；Hammack §§11.3–11.4、MIT §9.10 |
| L15 模整数入口 | `n∣(a−b)`；余数代表；集合 `Z/nZ`，n 为正整数 | L14、L04 | 写出模 4 的四个类，给负整数找到所属类 | 识别“元素是类”；不展开群、陪集、理想与商环理论；Hammack §11.5 |
| L16 基础计数规则 | 不重叠分支用加法；分步选择用乘法；允许重复 | L01 | 长度 k、每位有 m 种符号的串共有 mᵏ 个 | 必须说明是否独立选择、能否重复；MIT §§14.1–14.3 |
| L17 排列与组合 | 顺序、重复、阶乘、排列数、组合数 | L16 | 从 5 人选 2 名代表，与选正副代表的答案为何不同 | 不讲生成函数、复杂容斥、组合恒等式专题；MIT §§14.4–14.5 |
| L18 鸽巢与碰撞 | 盒子如何定义；超过容量必有重复；推广形式 | L15、L16 | 任取 6 个不同整数，必有两个模 5 同余 | 必然碰撞不等于随机碰撞概率；MIT §14.8 |

证明在 L04–L09 集中训练，也用于后续单满射、等价关系和鸽巢题。每个主题至少要求一句“为什么”，防止后半程退化为记定义和公式。

### 需要准确掌握的少量公式

| 公式或定义 | 必须同时理解的条件 |
| --- | --- |
| `P⇒Q` 与 `¬Q⇒¬P` 等价 | 不可据此断言 `Q⇒P` |
| `¬(∀x P(x)) ⇔ ∃x ¬P(x)` | 量词的论域不变；存在量词的否定同理 |
| 基例 P(n₀)，且对任意整数 k≥n₀ 有 `P(k)⇒P(k+1)` | 起点 n₀ 为整数；由此覆盖所有整数 n≥n₀；基例不可省略 |
| 单射：`f(x)=f(y)⇒x=y`；满射：`∀b∈B, ∃a∈A, f(a)=b` | 函数须先明确为 `f:A→B` |
| 等价类 `[a]={x∈S:x∼a}`；模 n：`a∼b ⇔ n∣(a−b)` | 一般等价关系先说明对象 S；模 n 此处要求 n 为正整数 |
| `P(n,r)=n!/(n−r)!`；`C(n,r)=n!/[r!(n−r)!]` | n、r 是整数且 0≤r≤n；选取不重复；前者计顺序 |
| N 个对象放入 m 个盒子，有盒子至少含 `⌈N/m⌉` 个对象 | m≥1；所有对象必须被分到某一盒子 |

同余只用于建立等价类的直觉。“模 n 的类组成商环”还涉及运算及良定义性；本阶段不把认识等价类说成已学会商环。群的陪集也有额外结构，留给目标课程。

### 本站之外的基础检查

完成本站后，建议另检查三个方向：能否读懂向量、矩阵和线性组合；能否读懂极限、求和与积分记号；能否区分概率中的事件、条件和独立。这里的选择来自课程领域的学习依赖，是准备建议，不是已经核实的官方先修清单。需要复习时转向相应本科材料，不在本站展开完整新课程。

目前不知道学生在这些方向的实际水平，也没有目标学期的题单，因此不能给出补齐 MFC 所有基础的总时长。12.5–15.5 小时只对应本站核心。

## 教学内容的组织

每节只解决一个主要问题。一个小节包含以下材料：

1. **目标与先修**：说明学完后能做什么，可用一题判断是否需要补先修。
2. **直觉与定义**：先给小集合、箭头图或余数盒子，再给严格定义及适用条件。
3. **示范与理由**：每一步都解释为何可以这样做，并指出一种不成立的走法。
4. **少量练习与分级提示**：先辨认，再补一步，最后独立写出短解。完整答案允许展开。
5. **稍后复验**：换一个参数或情境，不给方法标签。题目已经看过或用过提示时如实记录。

这种组织来自 [aime 的公开学习结构](https://aime.kapy.ca/) 和 [Levin 的在线教材](https://discrete.openmathbooks.org/dmoi4.html)。它与 IES 指南建议的例题和练习交替、具体和抽象表示结合、间隔回顾相符。它支持设计选择，不证明本项目已经取得学习效果。[IES 指南](https://ies.ed.gov/ncee/wwc/PracticeGuide/1)

题目使用自编基础题与筛选后的教材题。每题标明考查目标、来源、所需先修、提示、答案、常见误解及许可。难度先按“辨认一个概念、连接两步、换情境选方法”分级；未试学前不宣称等级已校准。

[三个核心教学样例及两张短衔接卡](02-teaching-samples.md)展示了此结构如何用于证明、等价类、鸽巢以及课程对象。样例为本项目自编的标准数学内容，不是 MFC 题单或所引教材题目的逐字翻译。

## 学习网站方案

学习入口显示当前路径、站内先修与可跳过内容，并写明“第一阶段离散数学准备”。完成页说明已经练习的能力，以及仍需另查的本科基础；不用“MFC 已准备好”作为完成标签。小节页把当前问题、必要定义和作答区放在一起。提示、完整解答和扩展材料按需展开。学习记录只显示实际作答、所用提示与稍后复验结果。

| 参考 aime 的组织 | 本项目的取舍 |
| --- | --- |
| 单元与小节，标明先修 | 保留，但压缩为明确的基础路径 |
| 目标、直觉、方法、带理由的例题、反例 | 保留，重点加强证明中“任意对象”和逻辑条件 |
| 基础、桥梁、综合练习 | 改为概念辨认、短推导、小迁移；不引入竞赛题强度 |
| 提示、曝光和延后复验记录 | 保留其区分原则，避免把看懂答案当作独立完成 |
| AI 对话等服务 | 是否需要在实现前再确定；当前内容方案不依赖 AI 自动判证明 |

未来可先用内容驱动的网页提供公式、可展开提示、固定答案与本地进度。正式证明题允许自由表述，并配检查要点和不同合理解法。选择题、配对题和具体数值题可以做规则核对；自由证明不能靠字符串匹配判断正确。

若以后加入 AI，AI 应指出具体推理缺口，接受合理的替代证明，并把判断保留为可核对反馈。登录、跨设备同步、纸笔上传、AI 服务和部署平台属于实现阶段选择，当前不决定或开发这些功能。

| 判断 | 现有证据 | 当前能得出的结论 |

| 所拟交互具有现成参照 | aime 公开课程数据与 Levin 在线教材 | 组织方式可借鉴；本项目尚未做浏览器或软件验证 |
| 内容可合法取得和使用 | 开放教材的明确许可及原文外链 | 非商业改编有路径；每条内容需保留来源和适用许可 |
| 与具体 MFC 的方向相符 | 已定位官方课程说明，明确背景水平与课程领域 | 可支持“先补证明及离散语言”的准备方向；不能声称覆盖全部先修或目标学期所有内容 |
| 18 节强度合适且有效 | 只有时间预算，没有试学数据 | 只能作为候选安排 |

下一步可在不制作网站的情况下，用三份核心样例做 2–3 名新生的小规模纸面或文档试学。观察能否读懂定义、能否解释例题的一步、独立题卡在哪里，以及每节实际耗时。隔 2–3 天再给未见新题。这个间隔是试教安排，不是已证实的最佳间隔。

试教暂以“能解释关键条件，且能独立完成一题同结构题和一题小迁移题”为工作门槛。若学生持续需要提示或单节超过 45 分钟，就拆节或减少符号密度。小样本只能暴露明显问题，不能估计普遍学习效果。当前未招募或联系学生，也未进行试教。

本阶段的交付终点是可审查的方案、来源和教学内容样例。课程身份无需再次澄清。若后续取得正式模块条目或获授权的目标学期讲义，只更新相应的先修判断与内容映射，不把课程资料受限作为现在扩课或实现网站的理由。
