# 本地首版验收结果

本文件记录首次 GitHub Pages 发布前的本地验收快照，课程内容版本 2026-11-17.1、Node.js v24.22.1。当时未部署或更改其它项目。后续线上发布及来源提交见 [发布说明](../DEPLOYMENT.md)。

**本地实现已补齐；自动检查和独立内容审查通过。真实浏览器体验验收尚未完成，因此不能宣称全部验收通过。**

## 实际执行

- 先制定 ACCEPTANCE.md，再实现网站。18 节核心和两张可选卡共含 60 道原创题。
- 运行 npm run check：11 个 JavaScript 文件及入口检查通过。
- 运行 npm test：26 项通过，0 失败、0 跳过。原始结果保存在 [测试日志](test-results.txt) 与 [语法检查日志](check-results.txt)。
- 模块渲染测试覆盖首页、20 节的四个阶段、练习事件、记录页、复验页、说明页和未知地址。它使用内存 DOM 宿主，不是浏览器。
- 本机服务启动前通过原生授权。12 个页面及资源返回 HTTP 200；研究目录、未知文件和 package.json 返回 404；POST 返回 405。服务只监听 127.0.0.1:4173。
- 代码依赖检查确认脚本与 CSS 本地提供，应用没有运行时 fetch、XMLHttpRequest 或 sendBeacon，也没有外部脚本或样式依赖。这是静态证据，不等同于浏览器断网实测。
- 真实浏览器工具返回“browser access host is unavailable”。没有绕过该限制安装或调用其它浏览器控制方式。

## 独立审查与修复证据

未编写相应部分的 agent 独立审阅数学内容和记录逻辑。数学审阅另用枚举核对 1/4、5/8、11/32 等概率。修正如下：

- 笛卡尔积题明确字母对象；鸽巢课节补上同余先修；独立抽样解释涵盖所有既往结果。
- 修复陈旧标签页覆盖帮助证据。帮助时间与首次作答时间分开保存；较晚看参考解不会改写较早无帮助作答的事实。
- 新证明使旧自评失效。自评绑定具体作答版本；旧页面不能替尚未看到的新版本自评。
- 异常日期被限制并容错，损坏记录不因日期格式化白屏。
- 目录标题可操作，避免从窄窗口切到宽窗口后被锁在关闭状态。
- 记录页显示选择内容，保留首次理由和修订；数值检查拒绝接近但不相等的答案。

修复前的记录问题由独立 Node 实验复现；修复后由回归测试验证。没有把这些实验称为真实浏览器验收。
